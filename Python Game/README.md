# Mau-Mau (Pygame)

Programming coursework: the Mau-Mau card game for one human and three computer players, following the rules in `Python Mau game description.pdf` (reduced deck, re-deal on four or more power cards, special effects for 7, 8, Jack and Ace).

```bash
pip install pygame
python main.py
```

The card-back images (`IMG_1211.JPG`, `nottingham*.jpg`) are loaded from this folder.
